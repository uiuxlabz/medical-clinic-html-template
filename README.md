# MEDINOVA — Medical Clinic & Healthcare HTML Template

**Healthcare You Can Trust.**

Premium, framework-free medical clinic website template built with semantic HTML5, custom CSS design system, and vanilla JavaScript. Designed for medical clinics, healthcare providers, and wellness centers.

---

## Pages

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Hero with tagline, departments grid, doctors, testimonials, appointment CTA |
| About | `about.html` | Clinic story, timeline milestones, core values, medical team |
| Departments | `departments.html` | Detailed cards for 6 departments with service lists |
| Contact | `contact.html` | Appointment form with validation, info cards, clinic hours |

---

## Features

- **Design System**: Full CSS custom properties (colors, typography, spacing, shadows, radii)
- **Color Palette**: Blue `#2563EB` + Green `#16A34A` + White `#F8FAFC` + Dark `#111827`
- **Typography**: Nunito Sans (headings) + Source Sans 3 (body) via Google Fonts
- **Responsive**: Breakpoints at 980px and 720px with mobile hamburger menu
- **Animations**: Scroll-triggered reveal animations via IntersectionObserver
- **Accessibility**: prefers-reduced-motion support, semantic HTML, ARIA labels
- **Forms**: Client-side validation with success/error feedback states
- **12 Images**: Hero, team photos, testimonials, about page

---

## Tech Stack

- **HTML5** — semantic markup, no frameworks
- **CSS3** — custom properties, grid, flexbox, animations
- **Vanilla JS** — modular IIFE, no dependencies

## Getting Started

1. Open `index.html` in any modern browser
2. No build step, server, or dependencies required
3. All assets load locally (fonts from Google Fonts CDN)

---

## Customization

- **Colors**: Edit CSS custom properties in `:root` in `assets/css/style.css`
- **Content**: Update text directly in the HTML files
- **Images**: Replace files in `assets/img/` keeping the same filenames
- **Fonts**: Swap Google Fonts `@import` URL in the CSS
